# Contributing

- Branch from `main`, keep PRs small, and fill in the PR template.
- One approving review from a code owner of each path you touch.
- Squash merge. The PR title becomes the commit message: `area: what changed (#PR)`.
- Hard-to-reverse choices get an ADR in `docs/adr/`.
- Coding agents follow [CLAUDE.md](CLAUDE.md): they ask Raven who owns a judgment call before they guess.
