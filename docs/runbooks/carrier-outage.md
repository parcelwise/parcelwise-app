# Carrier outage

Use this when a carrier's label API fails for more than five minutes.

1. Check the carrier status page and #carrier-ops.
2. Post in #incidents: which carrier, since when, what merchants see.
3. Don't switch a merchant's carrier for them. Tell affected merchants in the dashboard banner that labels for
   that carrier are delayed.
4. When the API recovers, nothing needs replaying: purchases were refused, not queued.

Owner: Carrier ops.
